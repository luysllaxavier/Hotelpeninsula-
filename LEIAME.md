# Hotel Península
1. Firebase Console: crie o projeto > Authentication > ativar "E-mail/senha" > crie seu usuário (e-mail e senha).
2. Firestore Database: crie o banco e cole o conteúdo de `firestore.rules` na aba Regras.
3. Configurações do projeto > Seus apps > Web: copie a config para `firebase-config.js`.
4. Authentication > Settings > Domínios autorizados: adicione o domínio do Netlify.
5. Suba esta pasta no GitHub e conecte ao Netlify (sem build, publish = ".").
6. No celular: abra o site e use "Adicionar à tela inicial" (Android: "Instalar app").
